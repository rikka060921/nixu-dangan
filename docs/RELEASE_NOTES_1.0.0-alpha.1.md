# 《逆序档案》1.0.0-alpha.1：双线回响

这是全新 1.x 规则的第一个可玩版本。0.x 已归档，本版本不要求玩家理解复杂结算，也能稳定打出时间线连锁爆发。

## 下载游玩

- 推荐下载 `reverse-archive-1.0.0-alpha.1-offline.zip`，解压后双击 `Reverse-Archive.html`。
- 也可以下载单独的 `reverse-archive-1.0.0-alpha.1.html`。
- 离线版不需要安装、命令行或网络；支持最新版 Chrome、Edge 与 Firefox。
- `SHA256SUMS.txt` 用于校验下载文件完整性。

## 这个版本有什么

- 同时操作过去与未来：每个过去选择会打开一组不同未来。
- 4 章双线案件、24 个路线节点和 12 张低文字量卡牌。
- 五张牌中选择三张，跨线越频繁，连锁越强。
- 未来回声可以送回过去，让关键动作再次发生。
- “一键爽打”自动找出当前最高爆发，不懂组合也能轻松通关。
- 第三轮紧急回溯、三档结案评价、卡牌奖励和完整双线结局。
- 300% 默认全局音量、场景 BGM、音量滑杆和本地断点存档。

## 已知限制

- 这是 1.x Alpha，首要目标是验证“双时间线爽游”是否有趣，内容量还不是正式商业版本规模。
- 音乐与音效为浏览器实时合成，首次点击或按键后才会播放。
- 存档只保存在当前浏览器，不会跨设备同步。
