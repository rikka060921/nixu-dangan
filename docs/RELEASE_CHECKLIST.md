# 1.0.0-alpha.3 发布检查

## 功能

- [x] 过去选择会切换当前可选未来。
- [x] 四章均可进入战斗、领取奖励并抵达结局。
- [x] 手动选牌、多套带理由参考打法、三牌排序与键盘操作可用。
- [x] 时间回传必须位于过去牌后，可选择回传目标，且正确重放目标到回传牌之间的牌。
- [x] 连续失败会降低通关目标，但不会自动补分或代替玩家通关。
- [x] 音乐在首次交互后启动，默认音量为 300%，并可持久化调整。
- [x] 新玩家会依次获得过去、未来、参考思路、回传目标、结算与得分记录的操作提示。
- [x] 教程可以重开、跳过，旧的回声术语不再出现在玩家操作链路中。
- [x] 四章开场与结算后剧情连贯，第一章四条未来路线有专属对话和规则说明。

## 数据与归档

- [x] 相同种子与相同决策保持确定性。
- [x] 1.x 使用独立存档键，损坏存档会安全忽略。
- [x] 0.x 已标记为 `v0.2.0-archive`，不再包含于主构建。
