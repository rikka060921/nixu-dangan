# 《逆序档案》1.x 开发路线

## 已冻结的产品目标

一款 3 分钟学会、每场都能打出时间线爆炸、理解越深越夸张的卡牌爽游。路线复杂度保留在地图上，战斗操作保持“选三张、看爆发”的轻量节奏。

## 已完成：1.0 双线纵切

- 过去选择动态改变未来路线。
- 未来回声可以倒灌并重复触发过去。
- 五选三有序连锁、自动最优解和第三轮通关保护。
- 四章流程、卡牌奖励、评级、结局、存档、音乐、在线与离线构建。

## 下一阶段：1.1 跨章因果

- 让早期路线改变后续章节的节点池、目标或特殊规则。
- 增加可在地图上预览的长线因果桥，避免结果变成隐藏数值。
- 为三种易懂流派增加视觉语言：伏笔爆破、证言扩散、回声改写。

## 后续阶段：1.2 爽感强化

- 连锁分镜、数字跳变、时间线塌缩与可关闭震动。
- 让音乐随接力次数逐层叠加，而不是只按页面切换。
- 依据真人试玩数据调整目标、奖励和自动方案提示。

## 设计门槛

1. 不读长说明也能得到正反馈。
2. 过去与未来的关系必须能在地图或结算中直接看见。
3. 自动操作能通关，手动理解能明显超越自动基线。
4. 相同种子与相同选择必须得到相同结果。
