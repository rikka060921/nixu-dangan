# 《逆序档案》1.0.0-alpha.3：时间回传更新

这个版本重做了战斗辅助和时间回传：系统会解释不同思路，但不再替玩家给出唯一最优解；未来也不再只是抽象加分，而是可以真正倒回某个过去时刻并重放。

## 下载游玩

- 推荐下载 `reverse-archive-1.0.0-alpha.3-offline.zip`，解压后双击 `Reverse-Archive.html`。
- 也可以下载单独的 `reverse-archive-1.0.0-alpha.3.html`。
- 离线版不需要安装、命令行或网络。

## 主要变化

- 辅助模式同时展示「稳妥得分」「时间回传」等参考打法，每套都列出选牌顺序、预计分数和选择理由。
- 采用参考打法后仍可自由换牌，没有一键自动结算。
- 「时间回传」需要亲手选择一张位于它之前的过去牌，并从那里开始重新结算。
- 结算记录会显示「时间倒流」和每一张被重放的牌，明确解释爆发从哪里来。
- 第三轮以后的保护仅降低通关目标，不再自动补分。
- 增加贯穿四章的剧情线，第一章的四条路线还有各自的对话与战斗影响说明。

1.0.0-alpha.1 与 alpha.2 的 1.x 存档可以继续使用。
