# 《逆序档案》1.0.0-alpha.2：新手引导更新

这个版本专门解决“第一次打开游戏，不知道档案、回声和闭环是什么意思”的问题。

## 下载游玩

- 推荐下载 `reverse-archive-1.0.0-alpha.2-offline.zip`，解压后双击 `Reverse-Archive.html`。
- 也可以下载单独的 `reverse-archive-1.0.0-alpha.2.html`。
- 离线版不需要安装、命令行或网络。

## 主要变化

- 新玩家进入第一关后，会依次看到五步操作提示。
- 红色明确写成“先做什么”，蓝色明确写成“后来变成什么”。
- “闭环目标”改成“通关目标”，“因果冲击”改成“得分”。
- “回声”改成“未来回传”，解释为“给下一张过去牌额外加分”。
- 卡牌效果改成更直接的短句和数字。
- “一键爽打”改成“一键推荐”，明确说明系统会自动选择最高分组合。
- 随机种子移入高级设置，首页只保留开始与继续两个主要操作。
- 右上角可随时重新打开新手教程。

玩法规则与存档格式没有破坏性变化，Alpha 1 的 1.x 存档可以继续使用。
