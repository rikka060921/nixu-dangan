# 当前开发状态

更新时间：2026-08-27

## 1.x 可玩纵切

- 产品方向：三分钟学会、每场都能打出时间线爆炸、理解越深数字越夸张的卡牌爽游。
- 路线结构：4 章双轨地图；每章有 2 个过去选择，每个过去会打开 2 个专属未来。
- 战斗结构：5 张手牌选 3 张并排序；换线接力、路线助力、过去改写与可选择目标的时间回传共同产生爆发。
- 辅助结构：同时展示多套参考思路，说明每张牌的用处、顺序、回传点和预计分数；不存在一键代玩。
- 难度保护：连续三轮失败后逐步降低通关目标，但仍由玩家完成组合；评级奖励未使用保护的玩家。
- 内容规模：12 张卡牌、8 个过去节点、16 个未来节点、4 个闭环目标与 3 档评级。
- 体验层：高对比度双线视觉、低文字量卡面、五步第一关操作教程、四章连续短剧情、路线专属对话、逐段得分解释、键盘快捷键、移动布局、场景 BGM 与 10%–300% 全局音量。
- 数据层：确定性种子、独立 1.x 断点与元数据，不读取或覆盖 0.x 存档。

## 自动化基线

- 测试：4 个 1.x/通用测试文件、13 项通过。
- TypeScript 类型检查：通过。
- Vite 常规、GitHub Pages 与单文件离线构建：通过。
- 离线 ZIP：包含单文件游戏、游玩说明、第三方许可与 SHA-256 校验。

## 归档决定

0.x 已在 Git 标签 `v0.2.0-archive` 固定，主分支不再编译旧规则、旧内容与旧模拟器。历史 Release 保留，旧版浏览器存档也不会被 1.x 删除。

## 已知限制

- 当前为 1.x Alpha，路线节点会改变战斗资源与开局牌，剧情会连续推进，但还没有跨章节隐藏路线。
- BGM 与音效由 Web Audio 实时合成，没有录制乐曲、插画和配音。
- 单局目前约 10–15 分钟；后续需要真人试玩验证数字爽感、路线复玩欲和卡牌辨识度。

## 下一轮候选

1. 收集首批试玩反馈，重点观察玩家能否说出两套参考打法的区别，以及是否会主动更换回传目标。
2. 增加跨章节因果：第二章的过去可改变第三章的未来池。
3. 增加失控连锁特写、屏幕震动开关和更强的分段音效。
